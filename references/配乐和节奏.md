# 配乐和节奏

这套流程做的是无旁白的片子：只有字幕和配乐，每屏的时间按配乐的节拍排。样本里 23 条历史文化类几乎全部无旁白，包括全部爆款。

## 1. 选曲

- 配乐用 CC BY 或更宽松授权的曲子，比如 Kevin MacLeod（incompetech.com，CC BY 4.0，简介里必须署名）。
- 【KV】也可以用 Wikimedia Commons 上公有领域的音乐，可商用。用过的：巴赫 C 大调前奏曲 BWV 846（Kimiko Ishizaka 演奏）、萨蒂《裸体歌舞》第一号（Robin Alciatore 演奏）。同一首曲子常有好几个演奏版本，先看频谱图里的底噪，有两个"公有领域"版本底噪太大没法用。
- 【KV】**别用爆款用过的曲子**：来源说不清，评论区很多人认得出来，显得像抄。
- 情绪和题材对得上，有起伏；没有旁白时，配乐就是片子的呼吸，答案揭晓、反转最好落在曲子的变化处。

## 2. 排时间轴

工具来自 knowledge-video：

```bash
python tools/beats.py audio/music.mp3 --json audio/beats.json          # 节拍、小节、每小节音量变化
python tools/music_loops.py audio/music.mp3 audio/beats.json           # 配乐不够长时，找能无缝重复的小节
python tools/cut_music.py audio/music.mp3 audio/beats.json --bars 1-6 29-45 46-83 -o audio/music_cut.wav
python tools/timing.py 文案.md audio/beats.json --bars 1-6 29-45 46-83 --anchor 42:83 --fix 1:6 -o plan.json
```

plan.json 定了以后，合成时不准改时间。

`timing.py` 的经验：
- **只锚定最后一屏**（`--anchor 末屏:结尾小节`）。锚定中间的屏，会把多出来的时间平均摊给前面每一屏，节奏会变慢。
- 每屏按"约 0.6 秒 + 每 6 个字 1 秒"算，英文单词算一个字，所以带英文的屏会偏短，用 `--fix 屏号:拍数` 放宽。
- 片名卡、答案揭晓、结尾这几屏用 `--fix` 多给几拍。
- 剪配乐时保留原曲最后几小节当结尾，片子自然收住，不用硬淡出。
- 【KV】自由速度或三拍子的曲子，`beats.py` 的 4/4 网格会越走越偏。改成把每次换屏吸附到前后 0.6 秒内最强的音符起点（librosa 的 `onset_strength` + `peak_pick`），换屏就落在钢琴的某个音上。
- 【KV】一句拆成两屏时，按字数分时长，不要平分。平分的话后半屏可能只有 2 秒，还没读完就没了。
- 不要为了对齐音乐拉长字幕。样本里卡不卡拍对爆不爆没有影响，读得舒服更重要。

## 3. 响度和成品音轨

- 【KV】钢琴独奏这类曲子原始响度很低（−26 到 −33 LUFS）。先轻压缩再拉响度，拉到 −15 就够，不要硬拉到 −14。
- 开头淡入约 1.5 秒；结尾用的是原曲自己的收尾就不用淡出，否则末尾淡出 2–3 秒。

```bash
# 剪好的配乐 → 成品音轨（把 87.3 换成"总长 − 2.5"）
ffmpeg -i audio/music_cut.wav -af "acompressor=threshold=-30dB:ratio=2,afade=t=in:d=1.5,afade=t=out:st=87.3:d=2.5,loudnorm=I=-15:TP=-1.5" -ar 48000 -c:a aac -b:a 256k audio/mix.m4a
```

画面渲染完后把音轨换进去，不用重渲：

```bash
ffmpeg -i renders/final-raw.mp4 -i audio/mix.m4a -map 0:v -map 1:a -c:v copy -c:a copy -shortest final.mp4
```

## 4. 音效（可选）

- 用现成的音效文件，不用代码合成的声音（合成的纸声、笔声混在音乐里像噪音）。
- 少：每次换场景一声，答案揭晓、反转各一声重音，其余每屏最多一两声。
- 【KV】轻，而且每一声都对着画面里一个看得见的动作。knowledge-video 的一条 3 分钟片子用了 29 个音效，都很轻；点题那句一个都没放，让它干净地落下来。
- 可商用免署名的音效：Kenney 的 CC0 音效包，HyperFrames 的 media-use 技能里带的 Pixabay 音效。
- 有音效时，先把音效和配乐混成一条，再做上面第 3 步的响度处理。
