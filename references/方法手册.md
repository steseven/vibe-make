# 方法手册：规律和依据

来源：抖音"Vibe知识大赏"话题下 202 条视频的拆解（2026-10，其中 139 条逐屏标注），加上作者自己做的 12 条视频里踩过的坑。标【KV】的条目整理自 knowledge-video（Win-Hao，MIT）10-12 版的文档。

**怎么读这份手册**
- 分组口径：点赞 ≥ 1 万左右算"爆"，几千算"中"，几百以下算"扑"。"冷启动"指账号前几条、还没起号时发的视频，排除大号自带流量。
- 每条都写了样本量。n 小于 15 的只能当参考，不算定论。
- 样本是从话题里搜出来的，有幸存者偏差；抖音不公开播放量，比的都是点赞。
- 规律会变。作者在 10-09 扩样本后复核，推翻了好几条旧结论（见第七节）。你积累了自己的数据后，用自己的数据改写这份手册。

---

## 一、文案

| 规律 | 依据 |
|---|---|
| **开头 3 秒内抛出问题，片中有明确的答案句，结尾回扣开头** | 冷启动爆款 73% 给了答案句，扑街组只有 22% |
| 第一屏用问句或陈述句都行。问句要问一个有画面的场景，或者"你该怎么办"，不要"为什么……"式的修辞问 | 冷启动问句开头中位 3.2 万（n=11），陈述句 1.1 万（n=26） |
| 陈述句开头的三种有效写法：一个反常识的结论；一串具体画面；一个故事现场（年份 + 地点 + 反常事件） | 前 15 名里三种都有 |
| **全片只围绕一个核心数字或年代**，不突然冒出新数字 | 作者第一条视频里 147.8、150、1500 接连出现，观众看乱了 |
| 答案是推出来的，不是硬给的：先讲机制，再给答案 | 同上 |
| **推理少一步，观众就掉队**。要补的是缺的那一步，不是每屏都加解释；开头的问题和中段的悬念可以悬一会儿，后面兑现就行 | 【KV】一条片子画面重做后，作者仍觉得"有点难懂"：画面出现了红线，却没有一句"一个人长得普通，只有特别善良你才会注意到" |
| 贯穿全片的比喻，第一次出现时在字幕里点名（"你的注意力是一个筛子："），不要只放在画面的小标签里 | 【KV】只放在画面里时，观众到兑现处接不上 |
| 举例不要只抛问题，每个例子带一句理由（"两样都差的店早倒闭了"） | 【KV】只问"好吃的店怎么都很破？"，观众停在问题上 |
| 数字和术语旁边配一句大白话："毫无关系"配相关系数 0.00，"一个高另一个就低"配 −0.83 | 【KV】 |
| 讲错觉时说"看起来"；顺口的句子容易说过头（"他们个个都有" → "他们有的多得多"） | 【KV】 |
| 文案避开"AI 腔"：短促断句、一句一个数字地堆；像老师讲给学生听那样连贯地说 | 国外创作者调了十多小时流程后的经验；DeepSeek 等模型写的文案也有这个毛病 |
| 证据最多两条，挑最贴近生活的 | 冷启动爆款的案例段中位 2 个；用 3–4 个研究的多在扑街组 |
| 每屏不超过 20 字；近似数加"约" | 15 字和 18 字之间没有差别 |
| 不要章节卡，不要课程感（"今天一个维度一个维度拆给你看"） | 章节卡最多的一条（8 个）扑了 |
| 结尾用金句，或者"一个被具体描述的人 + 一个动作" | 金句结尾转发率 14–26%；让人想起一个具体的人的结尾转发率最高 |
| "评论区告诉我"能不写就不写 | 扑街组 30% 用了，爆款 12%。小红书投薯条时诱导互动的话会被拒 |

**文案交审前的自检清单**
- [ ] 只有一个核心数字或年代，没有突然冒出的新数字
- [ ] 答案是推出来的，推理中间没有跳步（找一个没看过研究稿的人读一遍，问哪里没跟上）
- [ ] 贯穿的比喻第一次出现时字幕里点了名；每个例子带一句理由
- [ ] 没有"AI 腔"：不是一串短句堆数字；讲错觉用"看起来"，没有说过头
- [ ] 证据不超过两条
- [ ] 开头 3 秒内有问题，片中有答案句，结尾回扣开头
- [ ] 每个指代都清楚（"再联系一下 ta"，ta 是谁？）
- [ ] 结尾的描述和片中的定义不矛盾
- [ ] 每屏不超过 20 字，近似数加"约"
- [ ] 每个数字、年代都能在 `article.md` 找到出处
- [ ] 没有章节卡、课程感、说教

## 二、时长、画幅、节奏

| 规律 | 依据 |
|---|---|
| **竖屏优于横屏**（冷启动账号） | 冷启动万赞率：竖屏 55%（n=11），横屏 33%（n=58）；中位赞 1.6 万对 470 |
| 70–90 秒和 130–170 秒都成立，超过 200 秒危险 | 冷启动爆款率：90 秒以下 50%（n=12），130–170 秒 57%（n=21）；200 秒以上扑率 64%（n=11） |
| 每屏约 3 秒；前 10 秒画面变化 5 次以上 | 爆款中位数 |
| 每屏开始都有一个看得见的变化，屏内一直有轻微运动 | 扑街组"基本不动"的屏更多 |

## 三、画面

| 规律 | 依据 |
|---|---|
| **这个赛道的画面几乎都是代码画的**：光点、线条、剪影、几何、扁平图标 | 以剪影、线条、几何、光点为主的：爆款 66%、中等 79%、扑街 65%；没找到用实拍照片的爆款 |
| 暗底 + 金色强调是默认样式，**安全但不加分** | 暗底 + 金色：爆款 76%、中等 79%、扑街 80%（爆 51、中 34、扑 20 条） |
| 想做出区别可以换配色，有成功先例 | 暗底 + 红色强调、浅色纸底（米白、羊皮纸）、霓虹色（黑底粉、深绿荧光）都有冷启动爆款 |
| 每段都要有和字幕对应的具体场景，人物用剪影、图标或光点 | 只有黑底文字和方格的视频扑了；几乎所有爆款都有具体场景 |
| 把数字演出来：粒子、图表生长、数字滚动、一排小人 | 头部爆款的主要动效 |
| 少用打字机、盖章、打叉 | 同一个题，特效多的版本 1720 赞，换成光影渐变的重制版 3.65 万 |
| 画面上不出现字幕里没有的数字 | 观众会去找这个数字是什么意思 |
| **开头 0.5 秒就有一个物件在动** | 8 条 5 万–25 万赞的爆款里，一半开头前 0.5 秒画面变化很剧烈（帧差 4–47）；作者自己 Opus 版的开头只有 0.9（n=8，参考） |
| 主体要清楚，但不必大 | 爆款主体外框中位占舞台 33%–49%，普遍留白多（n=8） |
| 质感层和材料处理让画面不廉价，但不是爆的必要条件 | 有一条 11.9 万赞的爆款是很素的光点风，细节密度比我们最素的一版还低。详见 `画面质感.md` |

## 四、包装

| 规律 | 依据 |
|---|---|
| 标题开头写"Vibe知识大赏｜" | 冷启动中位赞：带前缀 1.6 万，不带 322 |
| 标题用陈述句："《概念名》+ 一句结论"，少用"你……吗？" | 冷启动问句标题中位 288，陈述句 8232 |
| 封面在抖音上不是决定因素 | 有一条 48 万赞的封面一个字都没有 |
| 片名卡可有可无；要加的话放在 10 秒左右，停 2–4 秒 | 爆款 20 条里 14 条有，扑街组也差不多 |

## 五、转发是最大的差距

- 收藏/赞不分爆不爆都在 23% 左右。
- **转发/赞**：样本中位 16%；186 条（≥30 赞）里低于 6% 的只有 11 条，全是扑街或待观察。
- 按题材：友情亲情 44%、爱情 23%、自我人生 16%、纯好奇 12%。"让观众想起一个具体的人"的题转发最高。
- 做法：文案里放一屏，让观众想到"这说的就是 XX"；但不要写"转发给 / @ 谁"，会被判诱导互动。

## 六、不用花精力的地方

这些在爆款和非爆款之间没有差别：
- 字幕用衬线还是黑体；每屏 15 字还是 18 字
- 人物用剪影还是卡通
- 换屏频率（两组都是每分钟 24–26 次）
- 转场方式（几乎都是渐变）
- **卡不卡音乐节拍**（两组都在随机水平）
- 有没有片名卡
- 标不标"AI 制作"（看不到限流）
- 简介里写不写数据来源

## 七、被推翻过的结论（提醒自己别迷信规律）

| 旧结论 | 后来 |
|---|---|
| 第一屏不能用问句 | 扩样本后反过来了，问句更好 |
| 必须横屏 | 竖屏更好 |
| 衬线字体、每句 15 字更好 | 只是一个大号账号的个人风格。**一个账号占了某组三分之一以上时，它的风格会被误当成规律** |
| 能模拟的题不一定更稳 | 扩样本后翻回来：冷启动可模拟强的中位 3.2 万（n=15），弱的 1041（n=39） |

教训：程序自动统计容易误判，比如片名卡识别会把引文卡也算进去。下结论前，头部样本要逐条人工核对。

## 八、选题参考（可选）

- 最稳的是"自我人生"类：努力、学习、熬夜、自律这些观众自己身上的事。冷启动中位 2.5 万（n=21）。
- 历史文化类冷启动 6 条中位 2.8 万，5 条过万，但转发率偏低。
- 纯好奇类最弱，冷启动中位 298。
- 【KV】10 月初话题前 8 名里有 7 条不讲 AI（运气、意外、相亲、命运、丝绸之路……），共同点是"一个人人心里都有答案的日常问题，用一个硬核概念回答"。
- 结论最好是"开脱"（不是你的错，是规律）或"珍惜"（你们拥有的很稀有）；指责观众的题会扑。
- **别跟风**：同一个题，首发版本冷启动能过万，跟风版本只有几百赞。查重要搜字幕全文，不能只看标题，一个概念可能已经是别人爆款里的一个片段。
- 别的平台（比如 B 站）已经讲火的概念更好，热度被验证过。
