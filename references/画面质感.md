# 画面质感：质感层、材料、运镜、开头

代码画的画面容易显得"简单"：平涂色块、固定机位、开头是一个昏暗的静止场景。这份文档讲四件补救的事，外加 knowledge-video 光点风的做法（第 5 节），工具在 `tools/fx/vibe-fx.js`，自动检查在 `tools/qa_gate.py`。

思路参考了 huashu-art-motion（alchaincyf，MIT）的经验："平涂之后至少做一样材料处理"、"成片质感层"、"运镜当标点用"。代码是重写的，而且用 Vibe 爆款的数据核对过哪些能用、哪些不能照搬（见最后一节）。

## 1. 成片质感层（每条都加，成本最低）

每帧把所有内容画完以后，调用一次 `FX.finish(ctx, t)`：

```js
const FX = makeFx(1080, 1920, { bloom: 0.35, grain: 0.07, grade: [255, 196, 130, 0.08] });
function draw(t) {
  // ……画场景、浮尘、暗角……
  FX.finish(ctx, t);
}
```

| 参数 | 作用 | 建议 |
|---|---|---|
| `bloom` | 泛光：只有亮处向外晕开（烛光、金字、日出、屏幕光） | 0.25–0.4 |
| `grain` | 胶片颗粒，每帧换图案，看起来是"活"的 | 0.05–0.08 |
| `grade` | 用柔光叠一层颜色统一色调：`[r, g, b, 强度]` | 暖调 `[255, 196, 130, 0.08]`；冷调 `[150, 190, 230, 0.06]` |
| `vignette` | 暗角 | 工程里已有暗角就设 0 |

- 字幕是 HTML 层，不受质感层影响，始终清楚。
- 全部只依赖时间和固定种子，同一帧每次渲染完全一样（实测过两次渲染逐像素一致）。
- 在《古人怎么刷牙》上实测：画面整体变暖，亮部轮廓有一圈柔光，平面上有细颗粒；不抢画面。

## 2. 材料处理：别让主体只是平涂

主体（工具、器物、人物的衣服）画完形状以后，至少做一样材料处理：

```js
ctx.save();
ctx.beginPath(); ctx.roundRect(x, y, w, h, h / 2);
ctx.fillStyle = '#8a5a34'; ctx.fill();
ctx.clip();
FX.texture(ctx, 0.3);              // 纸纹颗粒：表面不再是一块死色
FX.shade(ctx, x, y, x, y + h);     // 从受光面到背光面：上亮下暗，立刻有体积
ctx.restore();
```

其他常用的材料手段（都能直接用 Canvas 做）：
- **轮廓光**：主体朝光源的一侧描一道亮边（`shadowColor` + `shadowBlur`），剪影最需要这个。
- **落地阴影**：物体下面一个压扁的径向渐变。
- **高光**：器物表面一条细长的白色渐变，金属、瓷器、漆器都靠它。
- **暗纹层**：背景里很淡的刻度、经纬线、古籍字、星图，透明度 0.04–0.1，让大面积暗底不显得空。

## 3. 运镜：镜头当标点用

分镜里每屏除了写"画面里什么在动"，还要写"镜头怎么动"：

| 镜头 | 用在哪 | `camAt` 里的写法 |
|---|---|---|
| 缓推 | 讲解、铺垫，慢慢靠近主体 | 缩放 1.0 → 1.15，`ease: 'io'`，跨整屏 |
| 横移 | 换段、时间线往前走 | 对准点 x 平移，缩放不变 |
| 拉远 | 交代全貌、段落收尾 | 缩放往回 |
| **快推** | **只留给揭晓和反转** | 0.25 秒推到 1.4–1.6 倍，`ease: 'snap'` |

规矩：推进去了要拉出来，不要连着三屏都往里推；快推全片最多两三次，用多了就不"响"了。

```js
const KEYS = [
  { t: T(12), s: 1.0, x: 540, y: 640 },
  { t: T(13), s: 1.12, x: 540, y: 640 },                 // 第 12 屏缓推
  { t: T(13) + 0.25, s: 1.5, x: 600, y: 620, ease: 'snap' }, // 第 13 屏揭晓：快推
  { t: T(14), s: 1.0, x: 540, y: 640 },                  // 拉回
];
const c = FX.camAt(t, KEYS);
ctx.translate(540, 640); ctx.scale(c.s, c.s); ctx.translate(-c.fx, -c.fy);
```

【KV】**推镜时别让画面压进字幕区**。推进去以后，主体下方的东西（坐标轴、标签、地面）会往下移，掉进字幕区。每个镜头关键帧都算一下最低的那个东西落在哪：

```
屏幕 y = 640 + (场景里的 y − c.fy) × c.s      // 竖屏；横屏把 640 换成舞台中心 y
```

竖屏要小于 1100（舞台下沿），超了就把对准点 `y` 往下挪，或者推得少一点。

## 4. 开头 0.5 秒：一个会动的主物件

第 1 屏 0.5 秒内，画面上要有一个和题目有关、正在动的东西：骰子落下、计数器往上滚、一把牙刷转过来被光照亮。不要从昏暗的空镜或标题开始。

依据：8 条 5 万–25 万赞的爆款里，一半开头前 0.5 秒的画面变化很剧烈（帧差 4–47），是一个物件马上动起来；《古人怎么刷牙》的 Opus 版只有 0.9，是一个昏暗浴室里的人影慢慢抬手。

## 5. 光点风和场景衔接（【KV】）

knowledge-video 做"夜空光点"风格时，第一版被作者评价"动作几乎没变化"：一张散点图占了半条片子，镜头不动，背景只有一层星星。第二版改了这些，作者觉得"不那么僵了"。场景本身要按新题目重新想，能带走的是做法：

- **每个点子找一个会动的东西**："一个高另一个就低"做成跷跷板，"都一样"做成一排一模一样的空壳。3 分钟 18 个场景，没有哪张画面占屏很久。
- **上一个画面变成下一个**，不硬切：片名的光点落进夜晚城市的窗户，再从窗户升起变成散点图；开头的跷跷板最后又坐回那条红线上。
- **发光的画法**：径向渐变的光点贴图用 `lighter` 混合（几千个点别用 `shadowBlur`）；线描三遍（宽而淡、中等、细而亮）出辉光，画线时带一个彗星头；缓慢漂移的星云、三层视差星空、几颗流星、暗角。
- **颜色有含义**，全片固定：比如金色是"还在你眼里的人"，灰蓝是"被筛掉的"。
- **数据的变化就是动作**：被筛掉的人像沙子一样落下，被带走的人像灯笼一样升起，还原时倒放。
- 光点组成的片名：用同一个字体把片名画成位图，按最远点采样取约 1000 个点。

## 哪些规矩不能照搬

拿 8 条爆款核对过，下面这些在 Vibe 赛道**不成立**，不要写成硬规定：

| 别处的规矩 | Vibe 爆款的实际情况 |
|---|---|
| 主体至少占画面一半 | 爆款主体外框中位只占舞台 33%–49%，普遍留白多。Opus 版 58% 反而最大。要求的是"主体清楚"，不是"主体大" |
| 蓝紫底多了显得"AI 味" | 一条 11.9 万赞的爆款几乎全是蓝紫（99%），另一条 13.6 万赞的 51% |
| 0.3 秒以上的空画面就是做坏了 | 爆款常用短暂黑场转场，最长 2.5 秒 |
| 画面越精细越好 | 有一条 11.9 万赞的爆款细节密度只有 0.017（光点、星点风），比我们最素的一版还低 |

所以：质感层和材料处理是"让画面不廉价"，不是爆款的必要条件。决定爆不爆的仍然是选题、文案和转发（见 `方法手册.md`）。

## 自动检查

成片和样片都跑一遍：

```bash
python tools/qa_gate.py final.mp4 plan.json
```

它只拦明显做坏的（开头黑屏、3 秒以上空画面、主体小到看不见），其余给黄灯提醒，并打印和爆款范围对比的数字。阈值和校准数据见 `tools/README.md`。
