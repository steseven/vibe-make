# 踩坑清单

渲染失败、画面不对、东西不见了、声音不对时，先查这里。标【KV】的几条整理自 knowledge-video（Win-Hao，MIT）的 pitfalls.md 和 sound.md，其余是作者自己做 12 条视频时遇到的。

## HyperFrames 合成

- 【KV】**同一个元素的同一个属性，两段动画在时间上不能重叠**（比如推镜还没结束，复位就开始了）。预览单帧看着没问题，渲染时会出错。一段结束再开始下一段；不同属性分开（视差用 x，浮动用 y）。
- 【KV】同一属性后面的 `fromTo` 要加 `immediateRender: false`，否则后面的状态（特别是镜头运动）会从第一帧就生效。
- 【KV】**整页的 id 不能重复**。重复的 id 会让动画悄悄作用到别的元素上。构建完扫一遍。
- 【KV】`<svg>` 上的 `data-start` 不生效，时间写在外面包的 `<div>` 上。
- 【KV】用 GSAP 动画 `clip-path: inset(...)` 可能让元素消失。改成动画一个 `overflow: hidden` 外框的宽度，或者用 `scaleX`。
- 【KV】运行时把文字拆成单字 span 做逐字动画时，给容器写的 `.head span` 样式会作用到每个字上，改成 `.head > span`。
- 【KV】故意让元素重叠时，`hyperframes check` 的版面检查会报错。确实是故意的，就加 `data-layout-allow-overlap` / `-occlusion` / `-overflow`。
- 【KV】模板放在 `src/` 里，不要放项目根目录：根目录有第二个带 `data-composition-id` 的 HTML，lint 会报 `multiple_root_compositions`。
- 【KV】跟着镜头一起动的标签画在 canvas 上（`fillText`）；固定在屏幕上的文字（字幕、读数）用 DOM。镜头旋转时把屏幕上的读数藏起来，否则它们会压在转过去的画面上。
- 【KV】打字机效果：居中的一行用隐藏 span 逐字显示，第 0 帧会整体偏左。第 0 帧先完整显示第一行，再打第二行。
- **所有随机数用固定种子**：同一帧每次渲染必须完全一样。
- **画面只能由时间决定**：不要依赖上一帧的状态，渲染器会跳着取帧。

## 字体

- **字体子集化会缺字**：构建时逐字检查子集是否覆盖全部字幕和画面文字（包括"“”"引号和生僻字），缺字会变成方块。
- 【KV】抖音美好体（Douyin Sans）的 GSUB 表不能子集化，加 `--drop-tables+=GSUB,GPOS`。
- 【KV】命令行找不到 `pyftsubset` 时，用 `python -m fontTools.subset`。
- 字体授权：思源宋体 / Noto Serif SC（SIL OFL）、马善政楷书 Ma Shan Zheng、霞鹜文楷（都是 OFL）可以放心用。Windows 自带的华文字体只在自己电脑上用，商用授权要自己确认，也不要随项目分发。

## 声音

- 【KV】渲染时每个 `<audio>` 的 `data-volume` 设 0.45 左右。几条音轨叠起来真峰值超过 −1 dBFS，HyperFrames 会在最后一步失败。
- 更省事的做法：渲染不带声音（或带一条低音量的参考轨），最后用 `ffmpeg -c:v copy` 把混好的 `mix.m4a` 换进去。
- 【KV】换音轨或重新编码前，先确认渲染文件比 `index.html` 新。`render | grep` 这种管道会吞掉失败的退出码，你可能把新声音配到了旧画面上。

## 截图和导出

- **浏览器无头截图（Edge / Chrome headless）底部会多出黑边**：`window-size` 包含边框，窗口开大一点（比如 1980×1180）再裁成目标尺寸。
- 【KV】画面细节多时，`--quality delivery` 渲染出来很大（3.5 分钟约 870 MB）。用 `-c:v libx264 -preset slow -crf 19 -pix_fmt yuv420p -c:a aac -b:a 256k -movflags +faststart` 重新编码，约 400 MB，看不出差别。

## Windows

- Python 读写 json 一律写 `encoding="utf-8"`，脚本开头加 `sys.stdout.reconfigure(encoding="utf-8")`。不写的话中文会被存成 GBK，或者打印成乱码。
- 几个子任务同时跑时，临时文件名里带上视频编号，否则会互相覆盖。

## 子任务

- **用"跑完就退出"的方式运行时，第 5 步不要交给后台子任务，自己在前台做完。** 比如 `claude -p "……"` 这种一行命令：主任务把合成交出去以后，以为这一轮说完了，程序就退出，后台子任务也跟着被停掉，结果没有成片。在聊天窗口里用没有这个问题。
- 子任务做完、预览服务器（`npx hyperframes preview`）要关掉，否则整个进程挂着不结束。

## 画面质量（看样片时重点查）

先跑 `tools/qa_gate.py`，它会列出"审片时重点看这几屏"。下面这些是门禁量不出来、要靠人看的：

- 主体太小、画面太暗：竖屏舞台中心约 (540, 640)，主体至少占舞台宽度的三分之一。
- 前一个场景的元素残留在后面几屏的背景里。
- **整片停在同一个布景里**：比如铁丝妈妈、小猴、布妈妈摆成一排，连着二十多屏只有小猴挪位置。门禁量不出来（试过按像素比相邻几屏，爆款里固定版面的片子也会被判成重复），要看拼板：连续 5 屏以上是同一个景别、同一个机位，就换景、推近或给特写。
- 手画得像手套或木板、手臂比例不对（两个人握手时一只手臂有别人两倍长）。
- 竖排古籍字、片名这类大字，在换屏时留下残影。
- 剪影站姿僵硬：要有肩膀和腰身。
- 关键屏的点子不够直观：比如"这已经是一把牙刷了"，让今天牙刷的轮廓移过去和古代牙刷重叠，比在古代牙刷上描一圈金线好懂得多。
