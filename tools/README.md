# tools：做视频用的脚本

都在 Windows 上测过，macOS / Linux 也能跑（命令里的 `python` 换成 `python3`）。公共依赖：Python 3.10+、numpy、ffmpeg。

| 脚本 | 用途 | 依赖 | 来源 |
|---|---|---|---|
| `beats.py` | 配乐的节拍、小节、每小节音量变化 → beats.json | — | knowledge-video |
| `timing.py` | 把每屏排到节拍上 → plan.json | — | knowledge-video |
| `cut_music.py` | 按小节表剪配乐，节拍网格保持精确 | — | knowledge-video |
| `music_loops.py` | 找能无缝重复或剪掉的小节 | — | knowledge-video |
| `qa.py` | 成片质检：每屏一帧的拼板、关键屏前后帧 | Pillow（可选） | knowledge-video |
| `qa_gate.py` | 成片门禁：明显做坏的亮红灯（退出码 1），其余黄灯提醒，并和爆款范围对比 | ffmpeg | 本 skill |
| `fx/vibe-fx.js` | 画面质感：成片质感层、材料处理、运镜关键帧（拷进 HyperFrames 工程用） | 浏览器 Canvas 2D | 本 skill |

来自 knowledge-video（https://github.com/Win-Hao/knowledge-video ，Copyright (c) 2026 Win-Hao，MIT）的 5 个脚本，只改了 UTF-8 读写（`qa.py` 另外加了竖屏拼板），许可证全文见 `LICENSE-knowledge-video`。和上游 10-12 版的脚本相同（上游 10-12 只更新了文档，新经验已整理进 `references/` 里标【KV】的条目）。

## 文件格式

**文案.md**：以 `| 数字 |` 开头的表格行是一屏，第 2 列是字幕（可以用 `**加粗**` 标关键词），第 3 列可选，是出处卡片；表格前的 `## 标题` 是段落名。

```
## 一、开场

| 屏 | 字幕 |
|---|---|
| 1 | 你每天早上起来，第一件事是**刷牙** |
| 2 | 可没牙刷的年代，古人拿什么刷？ |
```

**plan.json**（timing.py 写出，合成时读，不准改）：每屏 `n`、`text`、`t`（出现秒）、`dur`（显示时长）等。

完整命令见 `references/配乐和节奏.md`。

## qa_gate.py 的校准数据

用 11 条片子定的阈值：《古人怎么刷牙》的三个版本，加上 8 条 5 万–25 万赞的 Vibe 爆款（5 条横屏、3 条竖屏）。原则是**红灯只放 8 条爆款全部能通过的项目**。

| 指标 | 8 条爆款 | Opus 版 | DeepSeek 照 Opus 分镜做 | DeepSeek 自己设计 | 门禁 |
|---|---|---|---|---|---|
| 第 0.5 秒舞台亮像素 | 6%–45% | 14% | 39% | **0%** | < 2% 红灯 |
| 片中最长空画面 | 0–2.5 秒 | 0 | 0 | **8.7 秒** | ≥ 3 秒红灯 |
| 主体外框中位（占舞台） | 33%–49% | 58% | 59% | **20%** | < 25% 红灯 |
| 开头 0.5 秒最大帧差 | 0.16–47（一半 ≥ 4） | 0.90 | 1.47 | 0.89 | < 1.0 黄灯 |
| 细节密度中位 | 0.017–0.133 | 0.076 | 0.073 | 0.026 | < 0.04 黄灯 |
| 几乎不动的屏占比 | 0–77% | 0% | 4% | 89% | > 50% 黄灯 |
| 蓝紫色占比 | 0%–99% | 13% | 19% | 0% | 不检查 |

结果：8 条爆款和 Opus 版、DeepSeek 照分镜版都没有红灯；DeepSeek 自己设计那版 3 个红灯（开头黑屏、1.0–9.7 秒空画面、主体太小）。

局限：只有 11 条片子；画面糊不糊、点子好不好懂这些，门禁量不出来，还是要人看拼板。"整片停在同一个布景里"也量不出来：10-19 试过按像素比较相隔几屏的画面，只用了 3 条样本片，它们就有 35%–55% 的屏和 5 屏前很像，比要拦的那条片子（10%–28%）还高，所以没加。

## fx/vibe-fx.js 的验证

在《古人怎么刷牙》的工程里加上质感层后，同一时刻渲染两次逐像素一致；纸纹图块平铺没有接缝；运镜关键帧（缓推、快推、拉回）在测试页里按预期工作。
